This project analyzes food sales data to identify sales patterns, revenue trends, and relationships that can support better business decision-making. The Python code uses Pandas to import, clean, organize, and analyze the Excel sales dataset, while Matplotlib and Seaborn are used to create visualizations. The project begins with exploratory data analysis, including descriptive statistics, missing-data analysis, and a detailed profiling report. It then uses pivot tables to compare product quantities by city, revenue by region, and sales by food category. The code also converts order dates into a time-series format to analyze monthly revenue trends by product and calculates year-over-year revenue changes
